## Translations ##

```php
$i18n = \Engine\Atomic\Lang\I18n::instance();
$i18n->t('auth.forgot.title');                  // nested key lookup
$i18n->t('title', [], 'dashboard');             // explicit domain
$i18n->tn('item', 'items', $count);             // plural
```

Dictionaries are read from every base path in this order (later wins): `LOCALES`, `app/Lang`, `<theme>/languages`.

### File layout ###

Either one file per language, a folder per language, or both:

```
languages/en.php            -> returns the whole nested array
languages/en/common.php     -> keys common.*
languages/en/auth.php       -> keys auth.*  (returns ['forgot' => ['title' => '...']])
languages/en/auth.json      -> also keys auth.*
```

`t('auth.forgot.title')` resolves from `en/auth.php`; call sites need no domain argument.

- Group file names must match `[a-z0-9_]+` and end in `.php` or `.json`; other files are skipped, as are files that do not return an array. Subfolders are not scanned.
- A group file named after the requested domain is not a group: `en/default.php` (default domain) or `en/dashboard.php` with `t($key, [], 'dashboard')` is merged at the root, as before. Called without a domain, `en/dashboard.php` is the ordinary `dashboard.*` group.
- After merging, a `$dict[<domain>]` subtree is lifted to the root.

### Precedence ###

Within each base path, each step overrides the previous:

1. `<lang>/<group>.php|json`, sorted by filename, under the key `<group>`
2. `<lang>/<domain>.php|json`, merged at the root
3. `<lang>.php|json`, merged at the root

So `en.php` overrides individual keys from `en/auth.php`; keys it does not define stay. A key missing in the current language falls back to the default language, key by key. The merged dictionary is cached per theme, domain and language when `i18n.ttl` > 0.

### Plurals ###

The language's plural rule picks a form. The first form uses the singular key; other forms try `<plural>.<form>` and fall back to `<plural>`:

| Language | Forms | Keys tried for non-first forms |
|---|---|---|
| en | one, other | `items` |
| ru | one, few, many | `items.few` / `items.many`, then `items` |
| uk | one, few, many | `items.few` / `items.many`, then `items` |

```php
// ru.php
return ['item' => '{count} предмет', 'items' => '{count} предметов', 'items.few' => '{count} предмета'];
```

Languages without a rule use the default language's rule.
